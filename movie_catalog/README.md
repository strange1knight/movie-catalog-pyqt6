# Моя фильмотека

Настольное приложение на PyQt6 для личного каталога фильмов. Можно добавлять
фильмы в планы, отмечать просмотренные, выбирать несколько жанров и оценивать их по шкале от 1 до 10,
записывать впечатления и прикреплять постеры. Данные сохраняются между
запусками в SQLite.

## Возможности

- Добавление, изменение и удаление фильмов с подтверждением удаления.
- Поиск по названию и заметкам; фильтры по статусу и любому из жанров фильма.
- Несколько жанров у одного фильма, пользовательские жанры и статистика по статусам.
- Выбор постера через стандартный диалог; изображение копируется в папку
  данных приложения, поэтому исходный файл после этого можно переместить.
- Двойной щелчок по фильму открывает редактор, правый щелчок — контекстное
  меню. Клавиши: `Ctrl+N` — новый фильм, `Ctrl+F` — поиск, `Enter` — правка,
  `Delete` — удаление, `F5` — обновление списка.

## Требования и запуск из исходников

Нужны Windows 10/11 и Python 3.10 или новее. Из корня репозитория:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r movie_catalog\requirements.txt
.\.venv\Scripts\python.exe -m movie_catalog.run
```

Для запуска из исходников PyInstaller не нужен; он включён в список
зависимостей для сборки `.exe`.

## Сборка standalone версии

Из корня репозитория после установки зависимостей:

```powershell
.\movie_catalog\build.ps1 -Python .\.venv\Scripts\python.exe
```

Результат — `dist\MovieCatalog.exe`. Формы Qt Designer встраиваются в `.exe`
командой `--add-data`. Файл можно перенести на другой компьютер с Windows без
установки Python и PyQt6. Для распространения рекомендуется проверить запуск
на чистой машине с той же архитектурой Windows.

## Где хранятся данные

SQLite-база и копии постеров сохраняются в папке данных пользователя,
полученной через `QStandardPaths.AppDataLocation`, обычно
`%APPDATA%\QtStudentProject\MovieCatalog`. База создаётся автоматически при
первом запуске. В ней три таблицы: `genres`, `movies` и связующая `movie_genres`. Чтобы сделать резервную
копию, закройте приложение и скопируйте папку целиком. Для изолированного
запуска можно задать переменную `MOVIE_CATALOG_DATA_DIR`.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `main_window.ui`, `movie_dialog.ui` | Две формы, редактируемые в Qt Designer |
| `main_window.py`, `movie_dialog.py` | Интерфейс и обработчики действий |
| `database.py` | Создание БД, запросы, запись и изменение данных |
| `paths.py` | Пути к ресурсам и данным пользователя |
| `run.py` | Точка входа |
| `build.ps1` | Сборка standalone `.exe` |

## Соответствие учебному заданию

Интерфейс создан в Qt Designer и содержит две формы и более пяти разных
виджетов. Используются стандартные диалоги (`QFileDialog`, `QMessageBox`,
`QInputDialog`), изображения (`QPixmap`), база из трёх таблиц с чтением,
добавлением, изменением и удалением, а также обработчики мыши и клавиатуры.
Содержательный код разделён на модули и превышает 500 строк. Проект рассчитан
на личную демонстрацию и защиту преподавателю.
